## ✨ Características

- **Gestión de Metas en Tiempo Real**: Creación, actualización y seguimiento visual de objetivos individuales y compartidos.
- **Arquitectura Client-First**: Actualizaciones optimistas y sincronización reactiva de estado mediante **TanStack Query v5**.
- **Diseño Modular y Accesible**: Componentes accesibles basados en **Radix UI** y estilados con **Tailwind CSS v4**.
- **Autenticación e Integración**: Backend ligero y reactivo potenciado con Firebase.
- **Rendimiento Ultrarrápido**: Empaquetado y recarga en caliente con **Vite 7** y gestión de dependencias con **pnpm**.

## 🛠️ Stack Tecnológico

- **Frontend Core**: React 19, TypeScript
- **Enrutamiento**: React Router DOM v7
- **Manejo de Estado Servidor**: TanStack React Query v5
- **Estilos**: Tailwind CSS v4, Lucide React, Radix UI
- **Backend / Persistencia**: Firebase
- **Tooling & Build**: Vite 7, ESLint, pnpm

## 🚀 Inicio Rápido

### Requisitos previos
- Node.js `>= 20.19.0` o `>= 22.12.0`
- pnpm instalado globalmente (`npm i -g pnpm`)

### Instalación local

```bash
# 1. Clonar el repositorio
git clone https://github.com/lucaszhh/metas-colaborativas.git
cd metas-colaborativas

# 2. Instalar dependencias
pnpm install

# 3. Iniciar el servidor de desarrollo
pnpm dev
```

La aplicación estará corriendo en `http://localhost:5173`.

### Construcción para producción

```bash
# Compilación y verificación de tipos
pnpm build

# Vista previa de la compilación
pnpm preview
```
